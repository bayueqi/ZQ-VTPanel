# ZQ-VTPanel

![页面](src/优化界面.png)
![页面](src/管理界面.png)

一个跑在 Cloudflare Workers 上的 VLESS / Trojan 节点面板：同一份代码既是节点隧道、订阅分发器，也是 Web 管理后台。

## 功能

- 面板三大块：订阅链接 / 基础配置 / 节点配置，毛玻璃动效界面，移动端自适应
- 优选IP、ProxyIP、入口地址、其它代理都支持多条，自由组合出节点
- 其它代理支持 `socks5` / `http` / `https` / `sstp` / `turn`
- 全局代理开关：只走代理，或直连失败回退
- VLESS / Trojan 独立或同时出订阅；自动识别 Clash / Sing-Box / Surge 客户端并调用 Sublink 转换
- ECH 加密、回退检测时间、优选IP 手动 / 定时更新
- UUID 登录鉴权，路径与参数伪装混淆

## 🚀 部署步骤

### 1. 部署到 Workers

1. 登录 Cloudflare 控制台
2. 左侧进入 **Workers 和 Pages**
3. 点击 **创建应用程序** → 选择 **创建 Worker**
4. 输入 Worker 名称并创建
5. 进入在线编辑器：
   - 删除默认模板代码
   - 打开本仓库的 `_worker.js`，复制全部内容
   - 粘贴到 Cloudflare 在线编辑器中
6. 点击右上角 **保存并部署**
7. 创建 KV 命名空间：
   - 左侧进入 **存储和数据库**，点击 **KV**
   - 点击 **创建命名空间**，名称建议：`VTPanel`
8. 在 Worker 详情页绑定 KV：
   - 打开 Worker → **设置** → **变量** → **KV 命名空间绑定** → **添加绑定**
   - 变量名称：`VTPanel`
   - 选择刚创建的 KV 命名空间
   - 点击 **保存**
9. 绑定自定义域名（注意：不能使用 workers 默认域名）

### 2. 部署到 Pages

1. [下载 ZIP](https://github.com/bayueqi/ZQ-VTPanel/archive/refs/heads/main.zip)
2. 登录 Cloudflare → **Workers 和 Pages** → **创建应用程序** → 选择 **创建 Pages**
3. 选择 **直接上传**，上传下载的 ZIP 包，直接保存并部署
4. 创建 KV 命名空间：
   - 左侧进入 **存储和数据库**，点击 **KV**
   - 点击 **创建命名空间**，名称建议：`VTPanel`
5. 绑定 KV：进入 Pages 项目 → **设置** → **变量** → **KV 命名空间绑定** → **添加绑定**
   - 变量名称：`VTPanel`
   - 选择已创建的 KV 命名空间
6. 再次上传 ZIP 包并部署，接着访问域名（可以绑定自定义域名，也可使用 pages 默认域名）

## 使用

首次访问输入默认 UUID `ef9d104e-ca0e-4202-ba4b-a0afb969c747` 登录，登录后立即修改 UUID。

### 订阅链接

复制订阅链接 / 导出节点 / 扫码，导入客户端即可。订阅地址带 `pwd` 参数即为登录凭据，注意保管。

### 基础配置

| 配置 | 说明 |
|---|---|
| UUID | 身份验证，同时是节点凭据；修改后需用新 UUID 重新登录 |
| 协议类型 | VLESS / Trojan，至少选一个 |
| 订阅转换服务 | 自建 Sublink Worker 根地址，留空用内置默认 |
| ECH | 加密 SNI 绕过 DNS 污染；「高级」里可改 SNI 与 DoH 地址 |
| 回退检测时间 | 直连无响应多少毫秒后切换下一通道，默认 100，范围 1-5000 |

### 节点配置

**优选IP 与 ProxyIP**

- 优选IP：客户端连接的入口（IP 或域名 + 备注），可点「自动优选」从 API 一键拉取
- ProxyIP：中转 IP，可加多条。填了 ProxyIP 后，每条「优选IP × ProxyIP」生成一个直连失败回退 ProxyIP 的节点；未填时只出直连节点

**入口地址 与 其它代理**

- 其它代理：代理列表，备注即节点名；格式 `[协议://]user:pass@host:port`，不写前缀按 socks5 处理
- 入口地址：客户端连接的入口，留空 = 本项目域名；与其它代理自由组合，各出一组节点
- 全局代理开关：开 = 只走其它代理；关 = 优先直连、失败回退其它代理

## 进阶

- **订阅转换服务**：面板填自建 Sublink 地址；也可用环境变量 `SUBLINK_BASE` 设部署级默认（面板保存过后以面板为准）
- **自动优选IP**：勾选「自动获取优选IP」后，在 Worker → 设置 → 触发器 → Cron Triggers 添加计划任务（如 `0 */6 * * *` 每 6 小时一次）
- **流量混淆**：WebSocket 路径伪装成普通 API 地址（如 `/api/v1/data`），回退参数用无意义短名，每个节点附带随机参数
