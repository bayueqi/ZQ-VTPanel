# ZQ-VTPanel

![页面](src/优化界面.png)
![页面](src/管理界面.png)

基于 Cloudflare Workers 的 VLESS / Trojan 节点面板：一个 Worker 同时承担节点隧道、订阅分发与 Web 管理界面。

## 功能

- 三板块 Web 面板：订阅链接 / 基础配置 / 节点配置，毛玻璃动效界面，移动端自适应
- 优选IP、ProxyIP、入口地址、其它代理均为列表，自由组合生成节点
- 其它代理支持 `socks5` / `http` / `https` / `sstp` / `turn`
- 全局代理开关：只走代理，或直连失败回退
- VLESS / Trojan 独立或同时出订阅，自动识别 Clash / Sing-Box / Surge 客户端并调用 Sublink 转换
- ECH 加密、回退检测时间、优选IP API 手动 / 定时更新
- UUID 登录鉴权，路径与参数伪装混淆

## 部署

### Workers（推荐）

1. Cloudflare 控制台 → Workers 和 Pages → 创建 Worker
2. 在线编辑器删除默认代码，粘贴 `_worker.js` 全部内容，保存并部署
3. 创建 KV 命名空间（建议命名 `VTPanel`），在 Worker → 设置 → 变量 → KV 命名空间绑定，变量名 `VTPanel`
4. 绑定自定义域名（Workers 默认域名不能用于节点连接）

### Pages

1. 下载仓库 ZIP → Workers 和 Pages → 创建 Pages → 直接上传
2. 同样绑定 KV（变量名 `VTPanel`）后重新部署

## 使用

首次访问输入默认 UUID `ef9d104e-ca0e-4202-ba4b-a0afb969c747` 登录，登录后**立即修改 UUID**。

### 订阅链接

复制订阅链接 / 导出节点 / 扫码，导入客户端即可。订阅地址带 `pwd` 参数即为登录凭据，注意保管。

### 基础配置

| 配置 | 说明 |
|---|---|
| UUID | 身份验证，同时是节点凭据；修改后需用新 UUID 重新登录 |
| 协议类型 | VLESS / Trojan，至少选一个 |
| 订阅转换服务 | 自建 Sublink Worker 根地址，留空用内置默认 |
| ECH | 加密 SNI 绕过 DNS 污染；「高级」里可改 SNI 与 DoH 地址 |
| 回退检测时间 | 直连无响应多少毫秒后切换下一通道，默认 100，范围 1-5000 |

### 节点配置

**优选IP 与 ProxyIP**

- 优选IP：客户端连接的入口（IP 或域名 + 备注），可用「自动优选」从 API 一键拉取
- ProxyIP：中转 IP，可加多条。填了 ProxyIP 后，每条优选IP × 每条 ProxyIP 生成一个「直连失败回退 ProxyIP」节点；未填时优选IP 只生成直连节点

**入口地址 与 其它代理**

- 其它代理：代理列表，备注即节点名；格式 `[协议://]user:pass@host:port`，不写前缀按 socks5 处理
- 入口地址：客户端连接的入口，留空 = 本项目域名；与其它代理自由组合，各出一组节点
- 全局代理开关：开 = 只走其它代理；关 = 优先直连、失败回退其它代理

## 节点回退逻辑

| 场景 | 行为 |
|---|---|
| 仅优选IP | 直连目标 |
| 优选IP + ProxyIP | 直连目标 → 失败换 ProxyIP 出口 |
| 入口地址 + 其它代理（全局代理关） | 直连目标 → 失败走其它代理 |
| 入口地址 + 其它代理（全局代理开） | 只走其它代理 |

回退顺序写在每个节点的路径参数里，由 Worker 在隧道层按顺序尝试，无响应超过「回退检测时间」即切换。

## 流量混淆

WebSocket 路径伪装成普通 API 地址（如 `/api/v1/data`），回退参数使用无意义短参数名，每个节点附带随机参数。

## 环境变量与定时任务

| 项 | 说明 |
|---|---|
| 环境变量 `SUBLINK_BASE` | 部署级默认订阅转换服务；面板保存过配置后以面板为准 |
| Cron Triggers | 面板勾选「自动获取优选IP」后生效，例如 `0 */6 * * *` 每 6 小时更新一次 |
